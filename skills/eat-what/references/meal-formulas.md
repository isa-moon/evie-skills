# 餐盘公式模板库

> 输出的是**"吃什么类别 + 具体到菜名的选项"**，不是菜谱。用户是上班族，只会在食堂、外卖、小店、便利店之间选。
> 所有量的依据见 `nutrition-cn.md`；盘子比例依据见 `nutrition-intl.md`（哈佛口径）。

## 通用结构

每餐按 **主食 / 蛋白 / 蔬菜 / 油盐** 四槽填空，另加「点单话术」。
早餐和加餐允许缺槽（见下），正餐三槽必须齐。

---

## 午餐 · 晚餐（正餐，四槽全上）

| 槽位 | 目标 | 落地选项池（按槽轮换，避免连续重复） |
|---|---|---|
| **主食** | 一拳大，尽量带全谷/杂粮 | 杂粮饭、糙米饭、荞麦面、玉米、红薯、土豆（算主食不算菜）、全麦馒头、藜麦饭、小米粥配饭 |
| **蛋白** | 一掌心。**优先鱼虾**（指南准则四原文"优先选择鱼"） | 龙利鱼/巴沙鱼、清蒸鲈鱼、虾仁、鸡胸/鸡腿（去皮）、瘦牛肉、豆腐/豆干、鸡蛋、鸭血、毛豆 |
| **蔬菜** | 两拳，**深色占一半** | 深色：西兰花、菠菜、油麦菜、小油菜、紫甘蓝、胡萝卜、番茄、彩椒、海带、木耳、香菇<br>浅色：白菜、冬瓜、莴笋、豆芽、白萝卜、藕 |
| **油盐** | 少油少盐，汤汁单放 | 见 `ordering-tactics.md` 的改造话术 |

**晚餐相对午餐的调整**：主食减到约 2/3，蛋白保持，蔬菜可加量。不搞"晚上不吃主食"——指南准则六明确反对过度节食。

### 正餐搭配的三条硬约束
1. **深色蔬菜必须出现**（指南：深色占蔬菜总量 1/2 以上）
2. **一周至少两次鱼**（指南准则四：每周最好吃鱼 2 次或 300~500 g）——查 `recent` 时留意，本周没吃鱼就优先排鱼
3. **加工肉不进推荐位**（火腿、培根、午餐肉、烤肠、腊肉）；用户点名要吃另说

## 早餐（指南准则六：每天吃早餐，不漏餐）

最低及格线 **主食 + 蛋白**，能加一样蔬果最好。

| 场景 | 组合 |
|---|---|
| 便利店/路边 | 茶叶蛋/水煮蛋 + 无糖豆浆/牛奶 + 全麦三明治 或 玉米/红薯 |
| 面食摊 | 小笼/蒸饺（带菜馅） + 一个蛋 + 豆浆（不加糖） |
| 粥铺 | 杂粮粥 + 鸡蛋 + 一碟小菜（**要求少盐**，腌菜别当蔬菜） |
| 公司食堂 | 杂粮包/馒头 + 蛋 + 奶 + 拌黄瓜 |
| 极限赶时间 | 牛奶一盒 + 水煮蛋 + 一根香蕉 |

**注意**：油条、煎饼果子、炸糕这类高油主食，可以吃但**不主动推荐**，一周不超一两次；腌菜咸菜不计入蔬菜量（高盐，指南准则五要求少吃高盐食品）。

## 下午茶 / 加餐

定位是**补日间缺口**，不是补零食。先看今天前面缺了什么：

| 今天缺什么 | 推荐 |
|---|---|
| 缺水果（指南 200~350 g/天） | 一份鲜果：苹果、橙子、梨、蓝莓、圣女果 |
| 缺奶（指南相当于鲜奶 300 g/天） | 无糖酸奶、纯牛奶一盒 |
| 缺坚果（指南每周约 70 g） | 一小把原味坚果（约 10 g，别选盐焗/蜜制） |
| 纯粹想吃点东西 | 无糖酸奶 + 少量坚果 / 水煮毛豆 / 一个水煮蛋 |

**不推荐位**：奶茶、蛋糕、饼干、含糖饮料（指南准则五：添加糖每天 ≤50 g、最好 <25 g；不喝或少喝含糖饮料）。用户主动要奶茶时不说教，给"减糖/去糖、小杯、换茶底"的降级建议即可。

## 夜宵

原则：**易消化、别太油、控量**，把它当加餐而不是第四顿正餐。

- 优先：一碗清汤面/馄饨（少盐、汤别喝完）、蒸蛋羹、无糖酸奶、热牛奶、水煮毛豆、玉米
- 慎选：烧烤、炸鸡、麻辣烫重油锅底、方便面
- 用户就是想吃烧烤时：给"多点素串、少点烤肠和五花、别刷太多油、配一份凉拌菜、别配含糖饮料"这类可执行的降级，不要劝退

---

## 轮换规则（配合 `profile_tool.py recent`）

- 出方案前必须跑 `recent --days 7`，把 `used_protein` 里出现过的蛋白**降权**，7 天内不重复推同一蛋白来源
- `rejected` 里的项：**换掉被拒的那个槽**，不是整套重摇
- 指南准则一要求"平均每天 12 种以上食物，每周 25 种以上"——这是主动换花样的依据，可以在解释里引用

## 特殊约束下的替换表

| 约束 | 蛋白替换 | 注意 |
|---|---|---|
| 素食 / 不吃肉 | 豆腐、豆干、腐竹、鹰嘴豆、毛豆、鸡蛋、奶 | 餐盘原文：「很容易将肉类替换为豆类，以获得充足的蛋白质」 |
| 不吃猪肉（宗教/偏好） | 鱼虾、鸡、牛、羊、豆制品、蛋 | 注意隐藏猪肉：高汤、肉末、荤油、猪油渣 |
| 不吃辣 | 蒸、煮、白灼、清炒路线 | 点单明确说"不要辣椒、不要花椒" |
| 牛奶不耐受 | 无乳糖奶、酸奶、豆浆（补钙另找：豆腐、深绿叶菜、小鱼干） | 豆浆蛋白够但钙远不如牛奶，别等量替换 |
| 预算紧（<15 元） | 鸡蛋、豆腐、豆干、鸡腿肉、当季蔬菜 | 便宜蛋白也能达标，别把预算和营养对立起来 |
| 时间紧（<10 分钟） | 便利店组合：即食鸡胸/茶叶蛋 + 沙拉 + 无糖酸奶 | 优于跳过一餐 |
