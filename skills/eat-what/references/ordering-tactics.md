# 点单话术与场景改造

> 这是 eat-what 区别于普通营养建议的地方：不止告诉用户吃什么，还给**能直接复制粘贴/照着念**的一句话。
> 依据：《中国居民膳食指南（2022）》准则七原文「在外就餐，不忘适量与平衡」。

## 通用改造指令（外卖备注 / 跟店家说）

按有效性排序，一次挑 1~2 条就够，别甩一串要求：

1. **「少油少盐」** —— 最通用，命中指南准则五（油 25~30 g、盐 ≤5 g/天），外卖备注栏最常被真正执行的一条
2. **「汤汁/酱汁单独装」** —— 比"少油"更可控，油盐大头在汤汁里，自己控制蘸多少
3. **「米饭换成杂粮饭/糙米饭」** —— 很多店有，不问就默认给白米饭
4. **「不要辣 / 微辣」「不要香菜」「不要葱」** —— 忌口直接写，别指望店家猜
5. **「加一份青菜」** —— 通常 3~8 元，是把蔬菜量补到 300 g 最省事的办法
6. **「肉去皮 / 要瘦的部位」** —— 对炸鸡、烤鸭、红烧肉类有效

## 分场景打法

### 公司食堂
- **打菜顺序**：先占蔬菜格子，再选蛋白，最后添饭 —— 顺序反过来容易蔬菜没位置了
- **两荤一素改成一荤两素**：同价位下蔬菜量翻倍
- 汤：多数食堂汤偏咸，**喝小半碗即可**，别把汤当补水（指南推荐白水或茶水）
- 避开：油炸窗口的复炸品、勾芡浓稠的菜（芡汁吸油）

### 外卖
- **搜索词决定结果**：搜"轻食"往往贵且吃不饱，搜 **"蒸菜""炖菜""快餐简餐""家常菜"** 更实际
- **看菜名判断油盐**：蒸/煮/炖/白灼/凉拌 < 炒 < 红烧/干煸/水煮/香锅/油焖
- 单点两菜一饭常比一份套餐更均衡，也更容易凑到深色蔬菜
- 备注栏写忌口 + "少油少盐"，**别写超过两条**

### 街边小店 / 快餐
- 面馆：**要求"少放油辣子、汤别太咸"**，加个蛋或一份青菜；汤别喝完
- 盖浇饭：**"汁儿少浇点"**，最有效的一句
- 麻辣烫/冒菜：多拿绿叶菜和菌菇，少拿丸子鱼豆腐（加工肉制品，指南准则四"少吃深加工肉制品"），**麻酱换蒜泥/清汤底**
- 沙县/兰州：蒸饺+紫菜蛋花汤、牛肉面加一份小菜，都是可行组合

### 便利店（赶时间的保底方案）
经典三件套：**即食鸡胸 / 茶叶蛋 / 豆干**（蛋白） + **沙拉 / 关东煮蔬菜**（蔬菜） + **饭团 / 玉米 / 红薯**（主食）
- 关东煮：选萝卜、海带、玉米、鸡蛋，**汤别喝**（钠很高）
- 避开：含糖饮料、膨化零食、加工肉肠

## 话术模板（填槽即用）

```
外卖备注： "{忌口项}不要，少油少盐，汤汁单独装"
食堂窗口： "一荤两素，荤的要{蛋白}，素的要{深色蔬菜}和{蔬菜}，米饭少一点"
面馆：     "一碗{面}，少油少盐，不要{忌口项}，加个鸡蛋"
盖饭店：   "{菜}盖饭，汁儿少浇点，米饭能换杂粮饭吗"
```

## 措辞纪律

- **不出现具体店名**。可以说品类（"找家做蒸菜的""川菜馆点这个"），不能说"你楼下那家 XX"——本 skill 不接任何地图/点评数据，编店名等于骗人。
- **不报价格**。没有数据源支撑，只能说"通常几块钱"这种模糊限定，或干脆不提。
- **不说教**。用户想吃炸鸡就给炸鸡的降级方案（配菜、去皮、别配可乐），不要劝退、不要评价用户的选择。
- **不提体重、BMI、热量缺口**，除非用户自己先提。
